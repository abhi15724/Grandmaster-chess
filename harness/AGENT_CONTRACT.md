# Agent Contract

The agents improve Grandmaster Chess while protecting correctness, trust, crawlability and maintainability.

## Agent team
- Growth Director: selects one useful growth opportunity.
- Chess Researcher: researches current chess topics and records sources.
- Article Writer: creates one original 1,500–2,200 word article.
- SEO/AEO Engineer: improves metadata, structured data, internal links and crawlability.
- Code Agent: implements only the scoped change.
- Independent Verifier: checks facts, originality, links, security, diff size, lint and build.
- Release Agent: creates a PR and releases only verified work.
- Learning Agent: records attempts, verifier feedback and measured outcomes.

## Never
- fabricate facts, sources, quotations, ratings or tournament results;
- copy or lightly rewrite other articles;
- create thin doorway pages or keyword spam;
- generate fake traffic, clicks or backlinks;
- expose secrets;
- edit production main directly.

## Required
- research time-sensitive claims;
- prefer primary and official sources;
- keep one clear search intent per article;
- run lint and build;
- have the independent verifier inspect the complete diff;
- learn from measured outcomes rather than self-generated claims.
